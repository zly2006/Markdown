# 0.1.0-alpha.1

2026-10-27 发布到 Maven Central。这是 `me.zly2006.markdown` 命名空间下的首个预览版，公开入口为：

```kotlin
implementation("me.zly2006.markdown:markdown-renderer:0.1.0-alpha.1")
```

## 模块与平台

包含 parser、runtime、renderer，以及对应的 LaTeX 和 CodeHigh 支持模块。八个模块采用相同版本，renderer 的 API 依赖会传递所需模块。KMP 根、Android、JVM、iOS ARM64、iOS Simulator ARM64 和 macOS ARM64 构件均已发布。

当前验证依赖组合为 Kotlin 2.4.0、Compose 1.11.1 与 Material 3 1.10.0-alpha05。Android 最低 API 27，JVM 目标为 Java 17。Apple 构件已编译验证；不将库编译成功表述为所有 iOS 设备场景均已验收。

## 现有能力与修复

保留知乎内置分叉的 AST、directive、公式、高亮、文字选择与惰性布局行为，并包含列表缩进与首行 marker 对齐、混排表格边框及超宽行内公式滚动修复。

## 迁移

Markdown 的 import 从 `com.hrm.markdown.*` 改为 `me.zly2006.markdown.*`。LaTeX 和 CodeHigh 类型仍使用其现有 `com.hrm.*` 包名，避免同时引入另一套包含相同类型的库。

Android 使用者的许可资源合并配置见根 README。原作者版权、分叉修改说明及 MIT/Apache 2.0 文本继续保留，见 `NOTICE.md`。
