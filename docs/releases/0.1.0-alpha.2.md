# 0.1.0-alpha.2

本版保留已提取快照的解析、渲染和惰性布局实现，更新到 Compose Multiplatform 1.12.2，与同系列 Skiko 0.150.2 重新构建全部支持模块。需要整体升级，不支持混用旧版选择与图像编码二进制接口。

## 兼容适配

- 选择布局构造传入上一布局，新手势清空旧布局信息。
- Android 与 Apple/JVM 的选择信息追加签名分别在平台工厂实现，共享缓存和文档顺序仍由原来的单个状态对象持有。
- 转发当前实际布局的 bring-into-view 能力；持久文本代理不固定惰性布局，保持选区跨离屏恢复的原有内存边界。
- 保留旧的空白区域选择行为，没有借 ABI 迁移增加新的鼠标选择策略。
- LaTeX 与 CodeHigh 同组重新编译，调用新 Skiko 的图像编码签名。

## 发布验证

JVM 测试、Android 与全部声明 Native 目标构建、签名与公共构件读回的终态，在发布完成后记录。未取得 Central PUBLISHED 不能作为应用的公开依赖交付。
